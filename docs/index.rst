########################################
NI Measurement Data Services for Python
########################################

The NI Measurement Data Services (MDS) help test and measurement teams store,
organize, and retrieve measurement data together with the context needed to
understand it. The V2 Data Store represents test execution as TestResults,
Steps, Measurements, and Conditions; the Python client lets you work with those
resources using Python and nitypes.

Guide to this documentation
===========================

Choose a path based on what you need:

* **Understand the model?** Start with :doc:`Concepts <concepts/index>` to see
  how MDS represents a test execution and how measurements fit into it.
* **Learn by doing?** Follow the :doc:`Tutorial <tutorials/index>` to create and
  read your first V2 measurement.
* **Complete a specific task?** Use a :doc:`How-to guide <how-to/index>` for
  installation, recording values, or querying data.
* **Look up an API?** Go to the :doc:`Reference <reference/index>` for the V2
  Python API and generated API details.

Runnable V2 notebooks are linked from the Tutorials section. They provide
longer examples for workflows such as batching, metadata, querying, and
measurement value types.
